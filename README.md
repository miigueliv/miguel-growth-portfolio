MIGUEL RODRIGUES — GROWTH MARKETING PORTFOLIO

Files:
- index.html: complete, responsive static portfolio website. Open it in a browser to preview.

BEFORE PUBLISHING:
1. Replace YOUR_EMAIL@example.com with the email address you want recruiters to use.
2. Replace https://www.linkedin.com/in/YOUR-LINKEDIN/ with your real LinkedIn URL.
3. Verify the metrics and descriptions, especially your exact contribution and attribution.
4. Add real campaign screenshots or work samples if you have permission to share them.
5. Review the About section and edit anything that doesn't sound like you.

FREE PUBLISHING WITH NETLIFY:
1. Visit https://app.netlify.com/drop
2. Drag the entire miguel_growth_portfolio folder onto the page (or zip it and upload the zip).
3. Netlify will publish it and provide a public URL.
4. Create a free account if you want to manage and update the site later.
5. You can change the generated site name in Netlify's site settings if the name is available.

Alternative: GitHub Pages supports free static hosting from a public repository:
https://docs.github.com/en/pages/getting-started-with-github-pages
